# slAIve

slAIve lives in your Mac's notch and shows what your coding agents are doing:
who is working, who needs you, on which account, and how much quota is left.

This repository holds **downloads, updates and feedback**. The source code is
private.

## Install

1. Open [Releases](https://github.com/kojicc/slaive-releases/releases) and
   download the newest `slAIve-….zip`.
2. Unzip it and move `NotchPets.app` to your Applications folder.
3. Open it. A paw appears in the menu bar.

slAIve is early and not yet notarized by Apple, so macOS may warn the first
time you open it.

## Updates

slAIve checks for a new version once a day and asks before installing it.
You can also choose **Check for Updates…** from the paw menu or Settings.

## Remove

In slAIve, open **Settings → Setup → Remove…** to take its hooks out of every
coding tool, then quit slAIve and delete the app.

## Feedback

Found a bug or want something? [Open an issue](https://github.com/kojicc/slaive-releases/issues/new/choose).

Issues are public. Please don't paste tokens, API keys, or logs that contain
private paths or conversation text.
